Como Utilizar

Passo a Passo

  1. Informe o número de funcionários do turno mais numeroso
  2. Selecione a jornada de trabalho
  3. Defina a proporção feminina para instalações separadas
  4. Ative o alojamento se houver pernoite na obra
  5. Configure opções adicionais conforme necessidade
  6. Clique em Calcular
  7. Ajuste os preços em Configurar Preços se necessário

Requisitos NR 18

  • 1 vaso sanitário para cada 20 trabalhadores
  • 1 mictório para cada 20 trabalhadores
  • 1 lavatório para cada 10 trabalhadores
  • 1 chuveiro para cada 10 trabalhadores
  • 1,50 m² de vestiário por trabalhador
  • 1,00 m² de refeitório por usuário
  • Ambulatório obrigatório a partir de 50 funcionários

Fórmulas de Cálculo

Vasos = ⌈N / 20⌉
N = número de funcionários
Área Vestiário = N × 1,50 m²
Assentos Refeitório = ⌈N / 3⌉
Considerando 3 turnos de refeição
Bebedouros = ⌈N / 25⌉
