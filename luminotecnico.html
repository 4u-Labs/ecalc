📝 Fórmulas Utilizadas (Método dos Lúmens)

Índice do Local: K = (C × L) / [Hm × (C + L)]

Fluxo Total: Φt = (E × A) / (FU × FM)

Nº de Luminárias: N = Φt / Φl

Iluminância Obtida: E = (N × Φl × FU × FM) / A

DPI: DPI = Potência Total / Área (W/m²)

Normas Técnicas Aplicáveis

📋
ABNT NBR ISO/CIE 8995-1:2013
Iluminação de ambientes de trabalho - Parte 1: Interior. Define níveis de iluminância, uniformidade e ofuscamento para diversos tipos de ambientes e tarefas.
📋
ABNT NBR 5413:1992 (Cancelada, ainda usada como referência)
Iluminância de interiores. Estabelecia valores de iluminância para diferentes atividades. Substituída pela NBR ISO/CIE 8995-1.
📋
ABNT NBR 5410:2004
Instalações elétricas de baixa tensão. Define requisitos para circuitos de iluminação, incluindo divisão de circuitos e proteções.
📋
Portaria INMETRO 144/2015 (Etiquetagem)
Requisitos de eficiência energética para lâmpadas LED. Estabelece níveis mínimos de eficiência e classificação energética.
⚠️
RTQ-C (Regulamento Técnico da Qualidade para Edificações Comerciais)
Define limites de Densidade de Potência de Iluminação (DPI) para obtenção de etiqueta PROCEL Edifica em edificações comerciais.
